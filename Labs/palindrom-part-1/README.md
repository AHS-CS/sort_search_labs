# Palindrome Part I

## Lab Goal

This lab is designed to review basic class creation, including instance variable definitions and method creation.

## Lab Description

Write a `Palin` class that tests whether a word is a palindrome.

A **palindrome** is a word that reads the same forwards and backwards.

Examples:

- `dad` is a palindrome.
- `racecar` is a palindrome.
- `dog` is not a palindrome.

The `StringBuffer` class may prove useful for this lab.

## Required Files

- `Palin.java`
- `PalinRunner.java`

## Sample Data

Test your program with the following words:

```text
dog
dad
racecar
goofy
madam
alligator
benjamin
```

## Sample Output

```text
dog is not a palindrome.
dad is a palindrome.
racecar is a palindrome.
goofy is not a palindrome.
madam is a palindrome.
alligator is not a palindrome.
benjamin is not a palindrome.
```

## Submission

Submit your completed Java files:

- `Palin.java`
- `PalinRunner.java`

Make sure your program correctly identifies each sample word as either a palindrome or not a palindrome.
